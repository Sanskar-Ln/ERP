# Jewellery & Gems ERP (MVP)

Multi-tenant SaaS ERP for Indian jewellery & gems retailers.
NestJS + Prisma + PostgreSQL API · Next.js web admin · Expo mobile ·
shared TS/zod package. pnpm monorepo.

- **PLAN.md** — milestone plan and the encoded 2026 GST facts
- **ARCHITECTURE.md** — system map and the non-negotiable rules
  (UUID PKs, integer paise, append-only documents, tenant-scoped queries,
  pure domain modules)
- **PROGRESS.md** — build log and resume point
- **REPORT.md** — final summary: what was built, how to run it, coverage,
  known gaps

Quick start: see “How to run” in REPORT.md. Demo login
`owner@demo.in / demo1234` after seeding.
